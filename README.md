# MPOAR LR's Item Collection
A mod for Metroid Prime Origins' Archipelago Randomizer, this mod adds a bunch of new items into the item pool, only compatible with the randomized version.

# What does it do?
It replaces a bunch of the missile expansions with custom items, these items may allow for sequence breaking and becoming a powerhouse, so do NOT get this mod if you don't want to break the balance. 
(Alternatively, increase the difficulty percentage in the settings)

# Installation
Initial setup
1. Follow [DodoBirby's MPO Archipelago Randomizer](https://github.com/DodoBirby/metroid-prime-origins-archi-rando/tree/main) installation instructions to get a patched data.win.
2. Download the latest [XDELTA file and APWORLD file in this repository](https://github.com/LinkedR/MPO-LR-item-collection/releases).
3. Patch the `randomizer's data.win` (source) using this `xdelta` (patch) file, you can patch files at [the xdelta patching site](https://kotcrab.github.io/xdelta-wasm/).
4. Install the [metroid_prime_origins.apworld from this repository](https://github.com/LinkedR/MPO-LR-item-collection/releases) into your [Archipelago Launcher](https://github.com/ArchipelagoMW/Archipelago/releases).

Seed generation
1. You can use the same `yaml` (settings) file from [DodoBirby's MPO Archipelago Randomizer](https://github.com/DodoBirby/metroid-prime-origins-archi-rando/releases), adjust accordingly.
2. Generate the seed as you would normally (or generated by the host) as instructed by [DodoBirby's general "Before Each Seed" instructions](https://github.com/DodoBirby/metroid-prime-origins-archi-rando/tree/main)

Launch
1. Launch the `Metroid Prime Origins client` through Archipelago Launcher. (not needed if you load an `.mposeed` file instead)
2. If all is successful, you should see `"Item Collection x.x.x"` in the menu (where `x.x.x` is replaced by a version number)
3. IF using the `MPO client`, you should see a connection message at the bottom right of the screen (can force-check with `F1`)

# Items
In-game names will display a shortened version of the actual item name, if you want to spawn or include the item in logistics (custom locations, requirements, etc...) you have to include `"LRItems "` at the beginning of the item name for it to recognise it, for example the id for `"Flash Shift"` would be `"LRItems Flash Shift"`! 
(I just made it this way just so the items do not conflict with anything else in the code if anyone decides to make other items with the same name or so)

# Dependencies
This patch requires very specific versions of MPO + AP Randomizer:  
Metroid Prime Origins required: `1.1.1 VM` 
Archipelago Randomizer required: `0.0.4`

# Issues
This is barely held together by an elastic band and it's quite an experimental project, so I will expect issues and possible crashing, if you want to report something it's probably best to inform me on Discord as I rarely check reports here.
